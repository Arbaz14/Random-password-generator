A secure, client-side password generator tool designed to produce strong, customizable, and cryptographically resilient random credentials directly in the browser.

---

## ✨ Features

- ⚙️ **Configurable Parameters:** Custom length controls, uppercase, lowercase, numbers, and special symbols toggles.
- 📋 **One-Click Clipboard Copy:** Instant copying to clipboard with visual feedback.
- 🔒 **Zero Data Transmission:** 100% client-side generation ensures private, unlogged passwords.
- 📱 **Clean Responsive UI:** Lightweight, mobile-friendly interface.

---

## 🚀 Quick Run

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Arbaz14/Random-password-generator.git
   ```
2. Open `index.html` in any modern web browser.
